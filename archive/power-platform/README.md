# Archive — Power Platform era

> **Nothing in this directory describes the system being built.**
> It is kept for the reasoning it contains, not for the decisions it records.
> The live architecture is [`docs/adr/ADR-035`](../../docs/adr/ADR-035-target-architecture-postgres-react-native.md).
> The live plan is [`docs/PLAN.md`](../../docs/PLAN.md).

## What this was

A Power Apps Canvas App on Dataverse, built to validate a data model for small
retail operators in Mexico. One of seven modules shipped (Comprar). Work stopped
on 2026-08-14 when ADR-035 replaced the whole stack with Postgres + React Native.

Per ADR-035 §1, stopping cost nothing: no operator was using the app, and all
Dataverse data was disposable. There was no migration and no cutover — seed data
is regenerated by script, not by ETL.

## Why it is archived rather than deleted

ADR-035 is built on what failed here. §2.3's "Deleted from the old model" section
is a direct response to specific defects in these documents, and the ADRs below
record genuine domain reasoning — expiry policy, product family/variant shape,
FEFO, waste handling — that survived the platform change even though the schema
did not. Deleting them would leave ADR-035's rationale unfootnoted.

## Four ADRs here are factually false

ADR-035 §1 audited the shipped module against its own decision records and found
schema claimed but never deployed. These are not merely superseded — they were
never true:

| ADR | Claimed | Reality |
|-----|---------|---------|
| ADR-034 | `ProviderProductPrice` table, "Go-Live Ready: Yes" | Not in the solution |
| ADR-023 | Alternate keys on six tables | Zero `EntityKey` definitions |
| ADR-002 | `Role` choice on `WorkspaceMember` | Column absent |
| ADR-011 | `QtyReceived = QtyRemaining = line qty` | Violated on every write |

That gap — decisions recorded as fact and never reconciled against reality — is
the specific failure ADR-035 §9 exists to prevent, and it is why the current repo
gates every schema claim on a green CI run rather than on a merged file.

## Also superseded

- `docs/migration/MIGRATION-BRIEF.md` — describes a five-phase parallel run and
  cutover. There is no parallel run and no cutover; ADR-035 §1 replaced it.
- `docs/alpha/ALPHA-SCOPE.md` — the seven-module Canvas roadmap. Abandoned.
- `issues/` — the Vertical 1 issues tracker. Closed with the platform.
