# site/ — the pages at tu-wera.com

Static pages, Spanish, no JavaScript — but one page's, since `10.9c` (`cocina/index.html`, below; the build check holds
its one script to reading the address bar). Written by plan task `5R-d-i`; published by `5R-d-ii`
through `.github/workflows/site.yml` (GitHub Pages), on every push to `main` that touches
`site/`. **This file is not published**: the build leaves it out. **Since `5R-r` (2026-11-20) the site has
pages of its own** — a page per app, the owner's page, *Tus datos* and *Ayuda* — in the words he approved on
2026-11-19, with the Wera mark in every page's header; the legal pages keep
their text and markup and take only the shared stylesheet. **Since `5R-s` (2026-11-20) it is drawn as the
paperwork of a counter** — his pick of three proposals, *A · Sello*: the grey of a counter, white sheets, perforated
tickets, rubber stamps inked in each app's colour, a notebook page, an envelope, kraft at the foot; Archivo and
Mansalva instead of Nunito; every movement CSS, and none when the phone asks for reduced motion (`estilo.css`'s
header says how each piece is drawn).

⚠️ **Rules for any word on the site's own pages** (his rulings): never *barrio* — *local*, *comercios
locales*, *colonia* only for a place; never *gratis* for Wera Cocina (a fee may come later; true, and said in person rather
than on the site since his review of 2026-11-20: *Durante el piloto no cobramos comisión*); never «lo que
sobra» where a fonda or neighbour reads (ruled 2026-11-05) — *aprovechar*, *vender hasta el último plato*; Wera Cocina and Wera (vecinos) are in no store yet — no store button for them, and
their line is *Ya en manos de sus primeros usuarios. Para todos, a fin de año.*; no prices; no phone number
in any file (the placeholders below); ⚠️ **never a sentence that talks down to whoever reads it** — his
ruling of 2026-11-20 on *Reglas claras sobre tus datos, en palabras de mostrador* (*"un poco denigrante"*), which
took with it *Sabe por fin…*, *para que una tienda sepa por fin…* and *les ayudo a entender sus números*: say what
the tool does for them, never what they lacked before it.

## ⚠️ Four placeholders, filled only when the page is published

`{{RESPONSABLE}}` and `{{DOMICILIO}}`, in both avisos: `privacidad/index.html` and
`privacidad/cocina-e-itacate/index.html` (the build prints how many times it filled each).
**Since `5R-r`, `{{WHATSAPP}}` and `{{WHATSAPP_TEXTO}}`** on the owner's page (`bernardo/index.html`,
*Hablemos*): the digits `https://wa.me/` takes (country code first, nothing else) and the number as the page
shows it. His number is never in this public repository — **the repository secrets `WHATSAPP` and
`WHATSAPP_TEXTO`**, passed in by `site.yml` like the other two. The build refuses either missing, `WHATSAPP`
that is not 10 to 15 digits, and a shown number whose digits are not the end of the dialled one.
The owner ruled that his full legal name and **home** address go in the aviso (2026-10-10).
This repository is public, so they are not committed here. **They are the repository
secrets `RESPONSABLE` and `DOMICILIO`**, set by the owner, and
`docs/checks/5R-d-ii-site-build.sh` fills them in at build time. It refuses to build when
any of the four is missing, when any `{{` is left, when a page loads anything from another site, or
when an internal link does not resolve (`5R-d-ii-site-build-falsify.sh` proves each refusal).
LIN Vigésimo primero asks for the street, number, colonia, alcaldía, postal code and
entidad — the address on file has all of them.

**To change any value**: change the secret (GitHub → Settings → Secrets and variables →
Actions), then *Actions → site → Run workflow*. No commit is needed.

## What had to be true BEFORE these pages went up (`5R-d-ii`)

1. **Supabase → Authentication → *Write audit logs to the database*: OFF**, and the
   table cleared once (`delete from auth.audit_log_entries`, run by the owner). Measured
   locally on 2026-10-12: deleting an account leaves GoTrue's audit rows behind, each with
   the person's email. With the switch off they live only in Supabase's log storage —
   1 hour on Free, 7 days on Pro (supabase.com/pricing) — which is what *"hasta 7 días"*
   on both pages rests on.
2. **The date** at the top of both pages is the day they are published.
3. **A page at the root** (`tu-wera.com/`): the *Wera* mark at the top of both pages links
   there. It is `index.html`, and it is also the support page.
4. **The hosting sets no cookies** (*"Este sitio no usa cookies"*). GitHub Pages sets none;
   GoDaddy's parking or forwarding pages do. `docs/checks/5R-d-ii-site-live.sh` asserts it
   on every page, against the live domain.
